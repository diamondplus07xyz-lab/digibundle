# DigiBundle - Ready-to-Post HD Reels Storefront

India's #1 modern digital reels bundle storefront with instant UPI checkout, Google Drive delivery, and built-in Admin management.

## 🚀 Quick Start

```bash
# Navigate to the project directory
cd "C:\Users\Admin\.gemini\antigravity\scratch\client 1"

# Run development server
npm run dev

# Or build for production
npm run build
```

The store runs at `http://localhost:5173/`.

---

## 🛠️ Key Features

1. **High-Converting Storefront**:
   - Live Countdown Sale Announcement Bar
   - Category filters (AI Avatars, Devotional, Money & Luxury, Gym, GTA 6, Anime, Memes, Satisfying)
   - Real-time search across all 2,50,000+ reels catalog
   - Reel Video Preview Modal (Mobile phone player mockup with play/pause)

2. **Automated UPI Checkout**:
   - Dynamic UPI QR Code generator (`qrcode.react`)
   - Direct UPI Intent buttons for PhonePe, Google Pay, Paytm, BHIM
   - 1-Click Copy UPI ID button
   - UTR / UPI reference number verification

3. **Instant Cloud Delivery**:
   - Confetti celebration upon payment completion
   - Instant 1-Click **"Open Google Drive Folder"** button
   - Detailed step-by-step usage guide (importing into CapCut/InShot/Instagram)

4. **"My Orders" Customer Self-Service**:
   - Customers can enter their WhatsApp number or Email to re-access their purchased Google Drive links anytime.

5. **Built-in Admin Dashboard**:
   - Click the Shield icon in the top header.
   - Enter default admin passcode: `admin123`
   - **Update your real UPI ID** (where payments will be sent)
   - **Update WhatsApp Support Number & Email**
   - **Edit Bundle Prices & Paste your own Google Drive links**
   - **Track Orders & Total Revenue** in real time!
